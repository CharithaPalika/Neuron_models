# 🧠 Neuron Models

An educational collection of **classic neuron model simulations** implemented in Python using Jupyter Notebooks.

This repository is intended for learning, experimentation, and visualization of how different mathematical models describe neuronal spiking and membrane dynamics.

> 📌 This repository is also used for the **Brain Modelling Workshop** conducted by **NeuroGATI**.  
> Learn more: https://www.neurogati.com/

---

## 🧬 Neuron Models Simulated

This project includes simulations of the following neuron models:

- **Hodgkin–Huxley Model**  
  A biophysically detailed conductance-based model explaining action potentials through sodium (Na⁺) and potassium (K⁺) ion channels.

- **Izhikevich Model**  
  A computationally efficient neuron model capable of reproducing a wide variety of spiking and bursting behaviors.

- **Leaky Integrate-and-Fire (LIF) Model**  
  A simple threshold-based model commonly used in large-scale neural simulations.

- **Morris–Lecar Model**  
  A two-dimensional conductance-based model used to study oscillatory and excitable neuronal behavior.

- **Quadratic Integrate-and-Fire (QIF) Model**  
  A nonlinear integrate-and-fire model that captures spike initiation dynamics.
